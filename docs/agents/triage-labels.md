# Rótulos de triagem

Os skills falam em termos de cinco papéis canônicos de triagem. Este arquivo mapeia esses papéis para os rótulos reais usados no Gitea deste repo.

| Rótulo em mattpocock/skills | Rótulo no nosso tracker | Significado                                    |
| --------------------------- | ----------------------- | ---------------------------------------------- |
| `needs-triage`              | `needs-triage`          | O mantenedor precisa avaliar esta issue        |
| `needs-info`                | `needs-info`            | Aguardando mais informações de quem reportou   |
| `ready-for-agent`           | `ready-for-agent`       | Totalmente especificada, pronta para um agente |
| `ready-for-human`           | `ready-for-human`       | Requer implementação humana                    |
| `wontfix`                   | `wontfix`               | Não será feita                                 |

Quando um skill mencionar um papel (por exemplo, "aplique o rótulo de pronto para agente"), use o rótulo correspondente desta tabela.

Edite a coluna "Rótulo no nosso tracker" para refletir o vocabulário que você realmente usa.
